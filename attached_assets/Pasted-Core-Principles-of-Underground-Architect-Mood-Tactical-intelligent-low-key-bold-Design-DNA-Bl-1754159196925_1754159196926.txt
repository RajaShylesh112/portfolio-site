🔧 NAVBAR — Tactical Rework
Your navbar should feel like part of a command line interface or schematic overlay, not a basic menu bar. Here's how:

🔹 Style:
Font: Monospaced (e.g., IBM Plex Mono, Space Mono)

Layout: Right-aligned or evenly spaced like terminal commands

Color: Desaturated white or soft blue; hover glow like HUD targeting

Background: Semi-transparent dark with grid lines or faint blueprint lines

Cursor hover: Subtle glow or underline that animates like a scanner beam

🧱 Page Add-ons for Depth
🔹 Homepage:
Hero Section: Your name fades in like a classified document unblurring

“CS student building backend systems that don’t just work — they scale.”

Tagline subtext:
"Under the hood, beyond the screen, behind the systems."

Add a schematic wireframe that pulses slowly in the background.

🔹 Blueprints (Projects):
Timeline view like a blueprint layout

Show tech stack per project like parts list:
CPU: Node.js | Data Bus: MongoDB | Control Flow: Express

Include a "strategy note": your decision rationale

🔹 Tech Stack (Skills):
Render as vertical bars or network nodes, not bullet points

Color-code: backend = blue, infra = gray, frontend = dim green

Include real examples:

"Built real-time logging system using Redis and Bun"

🔹 About Page:
Make it read like a dossier:

Education → “Foundational Training”

Interests → “Tactical Curiosities” (RDR2, Cyberpunk, etc.)

Include timeline / milestones in minimal scroll layout

🔹 Field Notes (Blog/Writing):
If you write occasionally (which you should):

Keep them as small logs

Use naming like: log_2025_08_02_building_scalable_auth.md

Think: hacker/dev log, not personal blog
