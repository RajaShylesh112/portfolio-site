Theme: The Underground Architect
🧠 Core Metaphor:
You are the quiet strategist — a builder with a masterplan, operating from the shadows.
Like Tommy Shelby or Dutch (when he wasn’t crazy) — you’re thinking in systems. You build for scale, but don’t chase the spotlight.

🎨 1. Visual Design
💻 Layout:
Grid-based, almost like floorplans or blueprints — reflects logic + control.

Section dividers use thin, blueprint-style lines, with labels like // PROJECTS, // ABOUT.

Cards are rectangular with strong vertical rhythm — echoing industrial or plan-drawing aesthetics.

🖋️ Typography:
Tall, condensed fonts with strong lines (e.g., Space Grotesk, IBM Plex Sans)

Optional: monospace subheadings to add a schematics feel.

🎨 Colors:
Element	Color	Rationale
Background	Deep navy / charcoal	Nightwork, secrecy, blueprint base
Accent 1	Cyan / teal	Blueprint lines, wireframes
Accent 2	Desaturated orange/rust	Old-world industrial (RDR2), adds warmth
Text	Light gray / white	Clean readability in a dark, high-contrast world

Optional: on hover, cards light up like table blueprints under a lamp.

🔲 2. Project Display (as “Blueprints”)
Each project = a system blueprint

Preview image = schematic view or API diagram (not just a screenshot)

Add “Blueprint Tags” for each:

makefile
Copy
Edit
STACK: Node.js | Redis | Docker
ROLE: Backend Lead
OUTCOME: 10x perf gain
On hover or click: micro-animations show the system flow (e.g., arrows animate to show backend flow).

✨ 3. Hero Section
💬 Headline Ideas:
“I build systems that scale in silence.”
“Quiet code. Loud outcomes.”
“Developer by trade. Strategist by instinct.”

Visual:

Left side = Name + tagline + CTA

Right side = slow-scan blueprint of a system diagram or “desk scene” (papers, map lines, maybe coffee mug?) — like a dev version of Tommy’s office.

Subtle Framer Motion animations for:

Cursor blink (like typing a command)

Hover reveals blueprint lines

Section fades that resemble old blueprints being unfolded

🔧 4. Contact + Footer = “The Backroom”
Treat the footer as your private workshop / smoke-filled backroom:

Contact form like a “confidential note drop”

Social icons subtly styled like file stamps (e.g., GitHub = “Archive #01”)

Optional fun tag: // BUILDING THE FUTURE IN PLAIN SIGHT
